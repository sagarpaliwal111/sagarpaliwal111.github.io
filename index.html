05AI-native engineering

AI writes the first draft. Engineers own the result.

AI coding agents are part of my daily workflow. I don't just prompt them: I build the skills, tool connections and guardrails that make them reliable on real engineering work.

Custom agent skills

Turned repeated engineering playbooks, like crash triage, log walking and release checks, into reusable skills and slash commands. Each one gives the same structured output every time.

Agents wired to real tools

Connected coding agents to code search, work tracking, chat and docs through MCP. Context comes from the source, not from copy and paste.

Parallel sub-agents

Fan out independent work, like triaging several issues at once or pressure-testing a root cause from three angles, then merge the results.

Guardrails first

Agents are read-only by default. Anything outward-facing, like a post, a push or a status change, needs explicit human sign-off. Every claim must cite a log line, file or record.
